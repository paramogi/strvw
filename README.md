# strvw

Tiny string view header, mostly meant for me, based on [this](https://gist.github.com/rexim/2bc46ae1aa18b9d05a4b3316f4f1aa1f).

Supports C99. Only tested on amd64. Only depends on libc.

## Usage

```
#define STRVW_IMPLEMENTATION
#include "strvw.h"
```

See examples.c for the rest.
